# Changelog

## 0.2.0 — release candidate

- Added appointment-business onboarding, staff scheduling, customer management, email delivery, and operational dashboards.
- Added durable AI chat and Baileys WhatsApp booking with encrypted credentials, staff takeover, and a persistent delivery outbox.
- Added tenant- and venue-scoped hybrid retrieval for FAQs, pasted text, and PDFs using PostgreSQL full-text search, pgvector, and a bundled multilingual embedding model, with citations shared by web chat and WhatsApp.
- Added owner-facing knowledge indexing and retrieval testing while keeping BYOK providers responsible only for final response generation.
- Added system health, persistent rate limits, safe structured logs, encrypted backup/restore, verified upgrades, support bundles, and bounded appointment analytics.
- Added immutable release-manifest, signing, clean-install, failure-drill, browser, accessibility, documentation, and full-day acceptance gates.

Release `0.2.0` is not published yet. Clean-host, live email/AI/WhatsApp, restore/upgrade, signature, and independent eight-hour acceptance evidence remain required before the annotated tag may be created.
