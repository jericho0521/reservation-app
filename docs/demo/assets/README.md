## Capture rules

1. Reset and verify deterministic demo data first.
2. Use a clean browser profile or presentation mode.
3. Capture the app viewport only; exclude terminal, address-bar tokens, notifications, and password-manager UI.
4. Inspect at full resolution for QR content, API keys, phone numbers, email addresses, management links/tokens, and raw channel identifiers.
5. Add the reviewer and date to this table only after approval.
6. Optimize file size without changing or compositing the product state.

Approved images are evidence and fallback visuals, not a substitute for recording the release-candidate revision in `docs/demo/demo-checklist.md`.
