# Run the staff working day

This guide is for reception staff and practitioners using the shared appointment command center.

## Start the day

1. Sign in and open **Reservations**.
2. Confirm the displayed local date and location.
3. Filter by practitioner, service, status, or customer search as needed.
4. Review pending appointments and any resource or practitioner conflicts before accepting walk-ins.

## Create or change an appointment

Use **Create appointment** for telephone, counter, or staff-assisted bookings. Select a service, practitioner, and live time before entering the minimum customer details. Never promise a slot until the create action succeeds.

For a reschedule, open the appointment, load current availability, and choose a new offered slot. If another booking wins the slot, refresh availability and ask the customer to choose again. Use cancellation and no-show actions rather than deleting history.

## Handle conversations

Open **Conversations** and filter by web chat, WhatsApp, or simulation. Read the timeline before replying.

1. Press **Take over conversation** before writing as staff.
2. Confirm the heading changes to **You are in control**. AI replies are now paused.
3. Send the direct response. Do not request passwords, payment-card data, or unnecessary personal data.
4. Press **Resume AI automation** only after the request is resolved and the assistant can safely continue.

If the inbox, availability, or delivery channel is degraded, keep the customer informed and tell the owner which safe status card or error code appeared. Do not copy raw provider payloads or QR data into messages.

## End the day

Review unresolved pending appointments, failed outbound work, and conversations still in manual takeover. Hand off those items explicitly. Staff should not run backup, restore, migration, or upgrade commands.
